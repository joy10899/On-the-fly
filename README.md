# On The Fly ✈️

On The Fly is a full-stack travel planner for creating trips, exploring
destinations, and organizing activities.

## Tech Stack

- React and Vite
- Node.js and Express
- PostgreSQL

## Run Locally

Start the API:

```bash
cd server
npm start
```

In another terminal, start the client:

```bash
cd client
npm run dev
```
